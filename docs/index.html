Rusty Cleaner scans your system for caches, duplicates, large old files, messenger media and more — then moves everything to the trash, never deleting anything outright. Fast, read-only until you say otherwise.

Everything a cleaner should do

🧹 Smart scanners

Temp files, browser caches, trash, duplicates, large & old files, orphaned app data and messenger media — seven specialized scanners.

🛡️ Safe by default

Nothing is deleted permanently. Files go to the system trash and can be restored from inside the app.

⚡ Rust fast

Parallel scanning with live progress, low memory footprint and instant startup. No Electron bloat.

💬 Messenger cleanup

Reclaim gigabytes from Telegram, Discord, WhatsApp, Signal, Slack and Element media caches.

🖥️ Cross-platform

Linux (incl. Omarchy), macOS and Windows — with native installers for each platform.

🔄 Auto-update

The app detects new releases and updates itself with one click from the dashboard.
