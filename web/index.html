      1. Get an API key Create a free key from any OpenAI-compatible provider. OpenAI (platform.openai.com), Groq (console.groq.com) and OpenRouter (openrouter.ai) all work. LM Studio and Ollama run locally and need no key.
      2. Pick a model OpenAI: gpt-4o-mini. Groq: llama-3.1-8b-instant. OpenRouter: any model with /api/v1. Ollama: llama3.1 or mistral. The model must support JSON responses.
      3. Paste and test Paste the base URL and key above, pick a model, toggle on, and click "Test connection". If it says Connected, you're done.
      4. What it does After a scan: a briefing card on the Overview explains what the junk is. In the results, the AI search bar filters by description ("browser caches over 50 MB"). Risk badges appear on findings.
      Privacy Only file paths (if allowed), sizes, and categories are sent. File contents, names, and personal data are NEVER sent. The key stays on your machine. Toggle off any time.
